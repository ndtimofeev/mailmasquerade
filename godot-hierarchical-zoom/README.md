# Непрерывный иерархический зум — демо на Godot 4

Галактика → звёздная система → бой одним непрерывным зумом, без смены сцен и затемнений.
Вид строго сверху, параллакс настоящими 3D-слоями звёзд. Всё генерируется процедурно.

Запуск: Godot 4.4+, «Импорт» → эта папка → F5.

Управление: колесо / Q E — зум к курсору; перетаскивание / WASD — панорама;
клик по звезде, планете, сражению или кораблю — плавный полёт к нему; Esc — уровень выше.

## Устройство

- `core/view.gd` — состояние камеры в double: фокус в галактических единицах и логарифм масштаба.
- `core/space.gd` — вложенное пространство со своими единицами; каждый кадр ставится относительно
  неподвижной камеры. Глубокие фоновые слои поджимаются к камере без изменения проекции.
- `world/galaxy.gd`, `world/star_system.gd`, `world/battle.gd` — содержимое трёх уровней.
- `main.gd` — ввод, полёты, создание и удаление систем и боёв по экранному размеру, подписи, HUD.
